# Brainbow: Escher

A "Deep Expression" Notebook, for use by makers who want to make .. things.

*Note: OR, REx Notebook ("Rapid Expression" Notebook)*
*Note: REx Mode: ("Rapid Expression" Mode)*

Point it at a folder on your system and get:

1.  An organized workspace designed for focused research.
    -   Optional built-in VsCode .. or bring your own editor.
    -   Share code to any* major package registry.
    -   Publish apps to any* major app store.
        -   .. or your own website.

2.  A multi-product workspace pre-configured for building full-stack applications for any* major platform.
    -   Build and run orchestrated services locally.
        -   Run directly in your apps/servers as native modules.
        -   Docker, wasm, lua, and v8 services supported.
            -   Coming soon: LLVM-based JIT Runtime
        -   Deploy them wherever* you want.
            -   Current: DigitalOcean, Fly.io, Cloudflare
    -   Current: Windows, macOS, linux, iOS, Android, tvOS, Roku
    -   Future: Playstation(?), Xbox(?), Switch(?)

3.  Build apps, servers, games, websites, and iot devices.
    -   Engine support for Bevy, Unreal, Unity, and Godot.

4.  All fully scriptable with your choice* of language(s):
    -   
    -   Current: Rust, Nu, TS/JS/AS, Python Dart, Lua, C, C++, C#
    -   Future: Java, Go, Swift, Kotlin, Vue, Svelte

5.  All open-source, MIT-licenced, free for everyone forever.
    -   Just make stuff and be kind, pls. <3

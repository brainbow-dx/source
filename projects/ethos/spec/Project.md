# Ethos

Codegen, management, and compiler for building native software from many languages. 

-   Build apps with whatever* language best suits the job.
    -   Current support for: Rust, JS/TS, Python, Lua, Dart, C/C++, C#
    -   Future support for: 
    -   Native plugin system.
-   Take as much or as little as you need.
    -   Start by generating a new project from a collection of simple pre-configured template repos (on github, for now).
    -   Write scripts in whatever* language you chose.
    -   Import only what you need:
        -   Slate for UI
        -   Eden for AI
        -   Atlas for Data
        -   Ethos for Codegen
    -   A few tools to help you:
        -   Sketch for UI/UX design/protyping
        -   Bench for workspace management
        -   HUD for quick tool access
